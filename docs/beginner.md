# 小白上手：只给抖音加一层分流

你需要一个已经能正常使用的代理客户端，以及自己的代理节点。本项目不含节点，不负责注册账号、购买软件或安装修改版抖音。

## 先准备好

1. 确认代理本身能用，并选择一个稳定的目标地区节点。建议先固定节点，不要自动在多个地区之间跳转。
2. 在客户端导出或复制当前配置。备份只留在自己设备，不要发到公开 Issue。
3. 确认客户端处于“规则/分流”模式。全局直连会忽略代理目标，全局代理会让媒体也绕路。
4. 打开[首页](../README.md)，找到你实际使用的软件。名字相近的客户端也可能用不同格式。

## 添加，然后选好代理

- Shadowrocket、Loon、Stash 优先走模块/插件/覆写入口。
- Surge 需要媒体模块和两条 API 代理规则共同生效，单独装媒体模块不够。
- 安卓客户端按各自教程处理，尤其不要把 v2rayNG 的规则片段当成完整路由列表直接导入。
- 文件里的 `Douyin-IP-Proxy` 是待你替换的目标策略名，不是项目提供的节点。把它改成客户端中**已经存在**的代理节点或策略组名称，字要完全一致。
- Xray / sing-box 的 `proxy` 是出站标签；它和界面中显示的节点名称不一定相同，相关教程有说明。

优先使用各教程给出的固定版本 Raw 链接，复制链接地址给支持远程资源的客户端；不要复制 GitHub 文件预览页地址。也可从 [v0.1.0 下载页](https://github.com/cazi-cc/douyin-ip/releases/tag/v0.1.0) 获取压缩包，按教程本地导入。需要选择策略或合并规则的软件，请先完成对应设置。

## 验证有没有生效

1. 退出抖音后台，断开并重连客户端，再打开抖音。先停用其他 VPN，避免两套规则互相覆盖。
2. 刷一些视频、打开评论和图文、切换直播，确认这些日常功能正常。
3. 看抖音个人主页和公开评论的属地。需要触发更新时，由你自行选择是否发布内容；另一个账号看到的新内容属地更有参考价值。
4. 网页 IP 查询只验证那个网站，不能代替抖音验收。属地也不一定马上刷新，不要反复换节点催它更新。

不需要输入账号密码、提交 Cookie、安装 HTTPS 解密证书，也不需要修改手机定位权限来使用本规则。

## 不满意就撤销

模块/插件/覆写用户停用本项目对应项；手动添加规则的用户删除本项目新增规则。若使用完整合并副本，切回之前的配置副本。然后重连客户端、重开抖音即可。[逐客户端操作](faq.md#如何撤销)

在你自己的设备上确认“刷得顺、属地对”才算成功，导入成功只是第一步。
